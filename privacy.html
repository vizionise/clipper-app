Clipper Privacy Policy

Last updated: November 17, 2026

Clipper is a personal tool used only by its owner to manage the owner's own YouTube channels.

What it accesses

With the owner's permission (Google sign-in), Clipper uses the YouTube Data API to upload videos to the owner's channels, read the status of those videos, and delete videos the owner chooses to remove.

What it stores

The Google sign-in token is stored only on the owner's own computer. Clipper does not run a server, does not collect data about anyone else, and does not sell, share or transfer any data to third parties.

Google API data

Clipper's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements, and the YouTube Terms of Service. Access can be revoked at any time at myaccount.google.com/permissions; see also the Google Privacy Policy.
