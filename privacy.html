Clipper Privacy Policy

Last updated: November 18, 2026

Clipper is a private tool used only by its owner to manage the owner's own YouTube channels.

YouTube API Services

Uses YouTube API Services

Clipper uses YouTube API Services. By using Clipper, users agree to be bound by the YouTube Terms of Service. Information is also handled according to the Google Privacy Policy.

What data it accesses

With the owner's permission (Google sign-in), Clipper uses the YouTube Data API to: upload videos to the owner's channels (videos.insert), read the title, status and view count of the owner's own uploaded videos (videos.list), read the owner's channel name (channels.list), and delete videos the owner chooses to remove (videos.delete).

How data is used, stored and shared

The Google sign-in token and the status and view counts of the owner's videos are stored only on the owner's own computer. They are used only to schedule uploads, detect removed videos and send the owner a private daily summary. Clipper does not run a server, does not collect data about anyone else, does not use cookies, and does not sell, share or transfer any data to third parties.

Data retention and deletion

Stored YouTube data (video status and view counts) is refreshed from the API at least every 30 days, and is deleted from the owner's computer when the owner revokes access or stops using Clipper. Access can be revoked at any time from Google's security settings at security.google.com/settings/security/permissions. To request deletion of any data, contact the owner below; it is deleted within 7 days.

Google API data

Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
